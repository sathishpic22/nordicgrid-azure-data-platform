# NordicGrid — Norwegian Energy Data Platform

An end-to-end Azure Data Engineering portfolio project
using real Norwegian electricity data.

## Architecture

Norwegian Energy API
        |
Azure Data Factory (Ingestion)
        |
Azure Data Lake Storage Gen2 (Bronze)
        |
Azure Databricks (Silver and Gold)
        |
Power BI

Apache Airflow orchestrates the entire workflow.

## Technology Stack

- Apache Airflow
- Docker Desktop
- Azure Data Factory
- Azure Data Lake Storage Gen2
- Azure Databricks
- PySpark
- Delta Lake
- Power BI
- GitHub Actions
